# เช็กลิสต์ทดสอบบนแท็บเล็ตจริง

ทำที่ยิมกับแท็บเล็ตเครื่องที่จะใช้จริง ติ๊ก ☐ → ☑ ทีละข้อ ข้อที่ไม่ผ่านให้จดในช่อง "ปัญหาที่พบ" ด้านล่าง แล้วส่งกลับมาให้แก้

- แท็บเล็ต: ________________ (รุ่น / iPadOS หรือ Android เวอร์ชัน)
- เบราว์เซอร์: Safari / Chrome
- วันที่ทดสอบ: ________________

## 1. ติดตั้งแอป

- ☐ **iPad**: เปิดลิงก์ระบบใน **Safari** → ปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น) → **เพิ่มไปยังหน้าจอโฮม** → เพิ่ม
- ☐ **Android**: เปิดลิงก์ใน **Chrome** → ⋮ → **ติดตั้งแอป** (หรือ เพิ่มลงในหน้าจอหลัก)
- ☐ ไอคอนดัมเบลสีม่วงชื่อ **GYMDOOD** อยู่บนหน้าจอ
- ☐ เปิดจากไอคอนแล้วเต็มจอ ไม่มีแถบที่อยู่เว็บ
- ☐ ล็อกอินครั้งเดียว ปิดแอปแล้วเปิดใหม่ยังล็อกอินอยู่

## 2. เช็กอิน

- ☐ กด **สแกนด้วยกล้อง** → อนุญาตกล้อง → สแกนบัตร QR จาก **หน้าจอมือถืออีกเครื่อง** ได้ภายใน 3 วินาที
- ☐ สแกนบัตร QR ที่ **พิมพ์บนกระดาษ** ได้
- ☐ (ถ้ามีเครื่องสแกน USB/Bluetooth) ตั้งแป้นพิมพ์แท็บเล็ตเป็น **ภาษาอังกฤษ** แล้วสแกน → เช็กอินทันที
- ☐ ผลขึ้นสีเขียว/เหลือง/แดง อ่านชัดจากระยะเคาน์เตอร์
- ☐ สมาชิกที่หมดอายุ: กด **ต่ออายุ** ไปหน้าขายได้

## 3. ขายและรับเงิน

- ☐ ขายแพ็กเกจ + สินค้าในบิลเดียว ด้วยเงินสด
- ☐ เลือก **QR PromptPay** → ใช้แอปธนาคารสแกนจ่ายจริง **ยอดเล็ก ๆ (เช่น 1 บาท ด้วยสินค้าทดสอบ)** → ยอดและชื่อบัญชีที่แอปธนาคารแสดงถูกต้อง → กด **ได้รับเงินแล้ว**
- ☐ เจ้าของ **ยกเลิกบิล** ทดสอบนั้นได้ และสต็อกคืน

## 4. พิมพ์

- ☐ **พิมพ์ใบเสร็จ** ผ่านเครื่องพิมพ์ที่ยิมใช้ (AirPrint / Bluetooth / เครื่องพิมพ์ในเครือข่าย) ขนาด 80 มม. อ่านภาษาไทยได้ ไม่ตกขอบ
- ☐ กด **คัดลอกลิงก์ใบเสร็จ** แล้วส่งทาง LINE ให้ตัวเอง → เปิดได้โดยไม่ต้องล็อกอิน และไม่เห็นเบอร์โทร
- ☐ **บัตรสมาชิก** → **พิมพ์บัตร** ได้ขนาดบัตร และ **บันทึกรูป** แล้วส่ง LINE ได้

## 5. สมาชิก

- ☐ **ถ่ายหรือเลือกรูป** ด้วยกล้องหน้า → รูปขึ้นในหน้าสมาชิกและตอนเช็กอิน
- ☐ ค้นหาสมาชิกด้วยชื่อไทยบางส่วน และเบอร์โทรได้

## 6. เน็ตหลุด

- ☐ ปิด Wi-Fi (และเน็ตมือถือ) → แถบแดง **ออฟไลน์ — ยังไม่ได้บันทึก** ขึ้นทันที และกดชำระเงินไม่ได้
- ☐ เปิด Wi-Fi กลับ → แถบหายเองภายในไม่กี่วินาที ใช้งานต่อได้

## 7. หน้าจอ

- ☐ ใช้งานได้ทั้ง **แนวนอน** และ **แนวตั้ง** ปุ่มกดด้วยนิ้วได้ง่าย
- ☐ เจ้าของเปิด **รายงาน** บนมือถือได้ อ่านตัวเลขได้
